# Student Management System

A web-based student management system built with PHP and MySQL that digitizes student record keeping for a school or college.

## Features
**Admin:** dashboard, manage classes, manage students, post class and public notices, search students by ID, view registration reports, update profile and password.
**Student:** login, view notices, view and update profile.

## Tech Stack
PHP, MySQL, HTML, CSS, JavaScript, XAMPP, phpMyAdmin

## Database
`studentmsdb.sql` contains 6 tables: tbladmin, tblclass, tblnotice, tblpublicnotice, tblpage, tblstudent.

## How to Run
1. Install XAMPP and start Apache and MySQL.
2. Open phpMyAdmin, create a database named `studentmsdb`, and import `studentmsdb.sql`.
3. Place the project folder in `htdocs` and open it in your browser.
